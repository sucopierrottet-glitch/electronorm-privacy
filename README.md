# ElectroNorm Pro — Política de Privacidad

Este repositorio aloja la página pública oficial de la Política de Privacidad de **ElectroNorm Pro** (desarrollada por **SimpleApps PG**), diseñada para cumplir con los requerimientos obligatorios de **Google Play Store** y **Apple App Store**.

## Enlace público de GitHub Pages

Una vez activado GitHub Pages en este repositorio, la política estará accesible públicamente en:

👉 **`https://sucopierrottet-glitch.github.io/electronorm-privacy/`**

## Aspectos destacados de la política

- **Arquitectura Local-First:** Todos los cálculos eléctricos, fórmulas, calibres, niples y proyectos guardados permanecen estrictamente en el almacenamiento local del dispositivo.
- **Sin cuentas ni registro:** No se solicitan correos, contraseñas ni datos personales obligatorios para operar.
- **Facturación segura:** Pagos y suscripciones delegados 100% a Google Play Billing y Apple In-App Purchases con cifrado oficial.
- **Cero telemetría:** Sin recopilación de datos técnicos de clientes ni proyectos para fines de analítica o publicidad de terceros.
